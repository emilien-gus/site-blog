# DevBlog — Веб-сайт блога на чистом PHP + Smarty + MySQL

Полнофункциональный веб-сайт блога на чистом PHP (без использования сторонних фреймворков), разработанный в рамках тестового задания. В проекте реализована классическая архитектура **MVC**, шаблонизатор **Smarty**, реляционная база данных **MySQL 8.0** и модульная стилизация на **SCSS** с компиляцией через **ScssPhp**.

---

## 🚀 Технологический стек

- **Бэкенд:** PHP 8.2-FPM (чистый PHP, без фреймворков, строгая типизация, PSR-4, PSR-12).
- **База данных:** MySQL 8.0 (InnoDB, кодировка `utf8mb4`, связь Many-to-Many, индексы).
- **Шаблонизатор:** [Smarty 5](https://www.smarty.net/) (наследование шаблонов `{extends}`, блоки `{block}`, компоненты `{include}`).
- **Стилизация:** Модульный SCSS с компиляцией в CSS через [ScssPhp](https://scssphp.github.io/scssphp/) (без зависимости от Node.js).
- **Веб-сервер:** Nginx (Alpine) с маршрутизацией через Front Controller.
- **Окружение:** Docker & Docker Compose (контейнеры `nginx`, `php`, `mysql`).
- **Менеджер зависимостей:** Composer.

## 📋 Реализованный функционал

### 1. Главная страница (`/`)
- Вывод категорий, в которых есть хотя бы одна статья.
- Для каждой категории отображаются последние 3 статьи (превью-изображение, заголовок, краткое описание, бейджи категорий, дата публикации, количество просмотров).
- Ссылка **«Все статьи категории &rarr;»** для перехода к полному списку статей рубрики.

### 2. Страница категории (`/category/{id}`)
- Название и описание категории, счётчик найденных статей.
- Интерактивная сортировка статей (с поддержкой JS и `<noscript>`-режима):
  - Сначала новые (по дате убывания)
  - Сначала старые (по дате возрастания)
  - По популярности (по просмотрам убывание)
  - По просмотрам (возрастание)
- Постраничная пагинация (по 6 статей на страницу) с сохранением текущих параметров сортировки в URL.

### 3. Страница статьи (`/article/{id}`)
- Полная информация: превью-изображение, заголовок, дата публикации, счётчик просмотров, список привязанных категорий.
- Полный текст статьи с сохранением абзацев и переносов строк.
- **Инкремент просмотров:** при каждом открытии страницы счётчик просмотров статьи автоматически увеличивается на 1.
- Блок **«Похожие статьи»**: до 3 статей из тех же рубрик (за исключением текущей публикации).

### 4. Обработка ошибок (404 Not Found)
- При обращении к несуществующей категории или статье отдаётся корректный HTTP-статус `404` и стилизованная страница ошибки со ссылкой на главную.

## 🛠 Быстрый старт и запуск

### Требования
- Установленный **Docker** и **Docker Compose**.

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/emilien-gus/site-blog.git
cd site-blog
```

### Шаг 2. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
*(По умолчанию в `.env.example` уже заданы рабочие настройки для локального запуска в Docker).*

### Шаг 3. Запуск контейнеров
Соберите образы и поднимите сервисы одной командой:
```bash
docker compose up -d --build
```

> **🎉 Всё происходит полностью автоматически!**
> Благодаря скрипту `docker/entrypoint.sh`:
> 1. Стили SCSS автоматически компилируются в `style.css`.
> 2. Контейнер ожидает готовности MySQL.
> 3. База данных проверяется и автоматически наполняется сидером (6 рубрик, 18 статей, 26 связей).

### Шаг 4. Открытие в браузере
Перейдите по адресу:
👉 **[http://localhost:8080](http://localhost:8080)**

## 💻 Полезные команды

| Команда | Описание |
|---|---|
| `docker compose up -d` | Запуск контейнеров в фоновом режиме |
| `docker compose down` | Остановка и выключение контейнеров |
| `docker compose exec php composer seed` | Повторный запуск сидера вручную |
| `docker compose exec php composer build-css` | Ручная пересборка SCSS в сжатый `style.css` |
| `docker compose logs -f [сервис]` | Просмотр логов (например, `php`, `nginx` или `mysql`) |

## 🧠 Архитектурные решения

1. **Автоматический запуск (Zero-config Setup):**
   Благодаря стартовому `entrypoint.sh` проверяющему достаточно запустить `docker compose up -d --build` — база сама инициализируется, наполнится статьями, а стили соберутся без ввода лишних команд.
2. **Front Controller & Роутинг:**
   Все запросы направляются через единую точку входа `index.php`. Роутер сопоставляет URL-маршруты и поддерживает именованные плейсхолдеры `{id}`.
3. **Безопасность (Prepared Statements):**
   Все запросы к БД выполняются через параметризованные запросы PDO. Прямая конкатенация пользовательского ввода исключена.
4. **Защита от проблемы N+1:**
   Для вывода категорий в карточках статей используется метод пакетной загрузки `Article::attachCategories()`, который подгружает все связанные теги одним SQL-запросом `WHERE article_id IN (...)`.
5. **Связь Many-to-Many:**
   Статья может принадлежать нескольким рубрикам одновременно (промежуточная таблица `article_category` с каскадным удалением). На основе этой связи работает алгоритм подбора похожих публикаций.
6. **Автокомпиляция SCSS в режиме разработки:**
   Приложение сравнивает время модификации исходных файлов `src/scss/*.scss` со скомпилированным `style.css`. При внесении правок в стили перекомпиляция происходит автоматически при перезагрузке страницы.
